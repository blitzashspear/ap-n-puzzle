# n-Puzzle AP Setup Guide

*Required Software*

- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)
- [The APWorld](https://github.com/blitzashspear/ap-n-puzzle/releases/latest)

*Playing The Game*

1. Download and install `n-puzzle.apworld`.
2. Generate a game with the APWorld.
3. Go to [the website](https://blitzashspear.github.io/ap-n-puzzle/).
4. Input the room information on the top left.
