# n-Puzzle

*What is this game?*

* It's the [sliding puzzle](https://en.wikipedia.org/wiki/15_puzzle).

*What are checks in this game?*

* Each individual tile's correct spot.
* Every successive correct spot you place a tile in.

*What options can I enable to spice things up?*

* The size of the board can be changed.
* DeathLink can be enabled.
